About

Used to code in high school by stealing code from Stack Overflow for GameMaker games. Now vibe-coding to make younger me jealous.

I do not just use Python. My focus is on HOI4 mods and mod tools, plus other games and random apps that come to mind.

  • Improving release pipelines and cross-platform packaging
  • Building UX that stays fast on large real-world datasets
  • Shipping practical tooling for collectors and HOI4 creators

Projects

album-detective

Desktop app for collectors to compare local music against Spotify and Jellyfin, detect missing albums, and review results with artwork-aware CSV tooling.

beigebox

Project M.A.D. -- Isometric RTS engine targeting circa-2005 hardware. C++17, deterministic lockstep netcode, Lua scripting, and an AI-assisted vibe-coding editor.

HearME

Single-binary desktop web app for music discovery. Artist relationship graph, tour grid from Bandsintown/Songkick, and a Winamp-themed audio player with real-time visualizers.

hoi4treesnap

Go-based HOI4 focus tree renderer with modern parsing, improved rendering reliability, Linux support, and production-style release packaging.

HOI4FocusGUI

Python-based Hearts of Iron IV mod GUI for generating and editing focus trees. Visual node editor, random tree generator, state viewport, and HOI4 export tooling.

HOI4-MCP

MCP server + agent skills framework that turns AI coding assistants into HOI4 modding experts -- deterministic mod data, syntax validation, zero hallucinations.

Mounter

GTK4 C++ desktop app. Scan for your SMB server and click mount -- no more manual fstab editing. Modern, fast, and frustration-free.

oddnetkernel

Custom Zen kernel for AMD desktops on Debian. Zen+ patches, Polaris GPU tuning, CIFS modules, and a one-line APT install. Built with Clang 21 + LLD.
